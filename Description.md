# ConceptSHOP Description

ConceptSHOP is a Profound Projects child repository for a shared product orders and stakeholder management platform.

The repo belongs to the Sentient OS workspace and is governed by the ConceptSHOP Repo Agent.

## Role In Profound Projects

ConceptSHOP provides an operational product/stakeholder surface for order tracking, product allocation, forecasting, marketing, shipping, chat, and dashboard workflows.

## Sapient Connection

Sapient memory lives in:

- `Description.md`
- `Architecture.md`
- `Decisions.md`
- `Roadmap.md`

These files describe identity, structure, durable decisions, and future direction.

## Sentient Connection

Sentient operations live in:

- `Agent.md`
- `Orchestration.md`

These files describe how agents execute tasks, validate work, and record operational history.

## Review-Sensitive Areas

Do not change these without explicit review:

- Authentication and route protection.
- Firebase service calls and data model behavior.
- AWS integration points.
- Forecasting logic.
- Order, shipping, stakeholder, and product workflows.
- Environment files and credentials.
- Dependency and build configuration.
